# Synthesis layer — one SLM call, one final ticket

Collects the REAL events of the whole pipeline per anomaly — edge
interpretation, diagnostic ticket (P5_verifier), prognostic forecast
(+ projected progression when progression_run exists), and the
deterministic signals — and has the SLM write THE final maintenance
ticket (SITUATION / DIAGNOSIS / OUTLOOK / TRUST / NEXT STEPS).

Design law: the composer may rephrase and organize, NEVER alter.
Gates: S1 sections, S2 severity/action/RUL/reliability/uncertainty
verbatim, S3 all citations present, S4 number conservation (no invented
figures). One repair, then a deterministic template renders the ticket -
output is guaranteed. The composer never sees ground truth.
Timing is collected per ticket (wall_s; --stats prints the table).
